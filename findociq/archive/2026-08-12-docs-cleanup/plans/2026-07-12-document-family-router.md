# Document-Family Router Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a document-level classifier that reads a bank-disclosure PDF and emits one manifest row `{path, family, institution, period, fs_subtype, has_contents_page, contents_page_number, confidence, flags}` so the correct downstream pipeline picks it up with no human sorting.

**Architecture:** One thin, testable module `findociq/pipeline/classify/family.py`. `family` is decided from **content** (page-1 text + geometry); `institution`/`period` are **filename** metadata (registry + regex); `fs_subtype` (advisory) and `has_contents_page`/`contents_page_number` (load-bearing FS hint) are content-derived. The router **classifies and emits a manifest — it never moves files and never invokes a pipeline.** The manifest (`out/manifest.csv`) is the visible decision-tree artifact and the hand-off contract to the per-family pipelines.

**Tech Stack:** Base python 3.12 venv, `pdfplumber` 0.11.9 (already in use). No paddle/heavy deps. Plain `check()` test scripts (no pytest).

**Binding spec:** `findociq/docs/specs/2026-07-12-document-family-router-design.md` (approved). Every design decision below is copied from it; deviations must be reported to the user, not worked around.

## Global Constraints

- **NO git commits, ever.** The owner batches commits manually. No task ends with a commit step.
- **Base python venv only** — `pdfplumber` 0.11.9, python 3.12. No PaddleOCR / MinerU / heavy deps.
- **Tests are plain scripts:** `check(name, cond, got)`, run as `python3 test_family.py`, exit `0` (all pass) / `1` (any fail). NO pytest.
- **Real corpus is the test ORACLE, not the source of rules.** Corpus root: `findociq/data/sources/{pillar3,presentations,financial_statements,regulatory}/`.
- **No per-bank / per-doc behavioral conditionals.** Every family/contents rule keys on a general content or geometry property that would work for a bank we have never seen. `INSTITUTIONS` is a metadata REGISTRY dict (onboarding a bank = one-line entry), never a behavioral branch. No `if OCBC/DBS/UOB` anywhere in behavior.
- **Fail loudly:** an unreadable/corrupt PDF → a row with `family="ERROR"` (never a skip). `build_manifest` emits exactly one row per input path, so `len(manifest) == number of input PDFs` always.
- **Module placement:** `findociq/pipeline/classify/family.py` — document-level classification, deliberately distinct from `findociq/pipeline/route/scan.py` (which routes *pages within* a document).
- **Delegation (CLAUDE.md):** delegated agents are NEVER Fable — `fast-worker` (Sonnet) for mechanical steps, `deep-reasoner` (Opus) for the regex/precedence reasoning in Tasks 3–4.
- **Tuning constants (module-level, exact values from spec):** `SLIDE_MAX_WORDS = 120`, `CONTENTS_SCAN_PAGES = 12`, `MIN_TOC_ENTRIES = 4`.

```python
"""family — document-level family/metadata classifier.

Reads a bank-disclosure PDF and returns ONE manifest row deciding its processing
family (pillar3 | slides | fs), institution, period, fs_subtype, and whether it
has a printed contents page. Content decides `family`; the filename supplies only
metadata (institution/period). Never moves files, never invokes a pipeline.

Spec: findociq/docs/specs/2026-07-12-document-family-router-design.md
"""
import argparse
import csv
import os
import re
import sys
from pathlib import Path

# ---- tuning constants (verbatim from spec) ----
SLIDE_MAX_WORDS = 120
CONTENTS_SCAN_PAGES = 12
MIN_TOC_ENTRIES = 4

# ---- institution registry: metadata only, one-line onboarding, never a behavior branch ----
INSTITUTIONS = {
    "DBS":  "DBS Group Holdings Ltd",
    "OCBC": "Oversea-Chinese Banking Corporation Limited",
    "UOB":  "United Overseas Bank Limited",
}


def parse_institution(stem):
    """First INSTITUTIONS key found as a case-insensitive SUBSTRING of the stem."""
    low = stem.casefold()
    for token, canonical in INSTITUTIONS.items():
        if token.casefold() in low:
            return canonical, []
    return "", ["no_institution"]


def parse_period(stem):
    """`<n>Q<yy>` -> `20yy-Qn`; else `FY<yy>` -> `20yy-Q4`; else ("", ['no_period'])."""
    m = re.search(r"([1-4])Q(\d{2})", stem)
    if m:
        q, yy = m.group(1), m.group(2)
        return f"20{yy}-Q{q}", []
    m = re.search(r"FY(\d{2})", stem)
    if m:
        return f"20{m.group(1)}-Q4", []
    return "", ["no_period"]
```

```python
import pdfplumber  # add to the import block at the top of the file


def read_doc_signals(pdf_path):
    """Extract page-1 text/geometry + first-N page texts. Raises on unreadable PDF."""
    with pdfplumber.open(pdf_path) as pdf:
        pages = pdf.pages
        if not pages:
            raise ValueError("no pages")
        p1 = pages[0]
        p1_text = p1.extract_text() or ""
        p2_text = (pages[1].extract_text() or "") if len(pages) > 1 else ""
        signal_text = p1_text if p1_text.strip() else p2_text
        pages_text = [(pg.extract_text() or "") for pg in pages[:CONTENTS_SCAN_PAGES]]
        return {
            "signal_text": signal_text,
            "width": float(p1.width),
            "height": float(p1.height),
            "p1_words": len(p1.extract_words()),
            "pages_text": pages_text,
        }
```

```python
# ---- fs keyword seeds: general-language, extended by adding words, never per-bank ----
FS_CORROBORATION = [
    "financial statement", "condensed", "interim", "unaudited", "results",
    "highlights", "performance", "trading update", "press release",
    "media release", "income statement", "balance sheet",
]

def decide_family(signal_text, width, height, p1_words):
    low = signal_text.casefold()
    if "pillar 3" in low:
        return "pillar3", "high", []
    landscape = width > height
    sparse = p1_words < SLIDE_MAX_WORDS
    if landscape and sparse:
        return "slides", "high", []
    if landscape or sparse:
        return "slides", "low", ["weak_slide_signal"]
    if any(kw in low for kw in FS_CORROBORATION):
        return "fs", "high", []
    return "fs", "low", ["weak_fs_signal"]


def decide_fs_subtype(signal_text):
    low = signal_text.casefold()
    return "full" if any(kw in low for kw in FS_FULL_KEYWORDS) else "highlights"
```

### Task 4: Contents-page detection — `find_contents_page`

**Delegate to `deep-reasoner`** — the two entry-line regexes and the label-guard rationale are the load-bearing FS signal.

**Files:**
- Modify: `findociq/pipeline/classify/family.py`
- Modify: `findociq/pipeline/classify/test_family.py`

**Interfaces:**
- Consumes: `pages_text: list[str]` (from `read_doc_signals`) — pure, so it tests synthetically AND against the real corpus.
- Produces: `find_contents_page(pages_text: list[str]) -> tuple[int, int]` → `(has, page_number)`. `has ∈ {0,1}`; `page_number` = 1-based index of the first qualifying page, or `0` if none.

**Rule (spec §has_contents_page), a page qualifies iff BOTH hold:**
1. **Label** — casefolded text contains `"contents"` or `"index"` (`"table of contents"` already contains `"contents"`).
2. **≥ `MIN_TOC_ENTRIES` entry lines.** Per line: collapse dot-leaders `re.sub(r"[.·…]{2,}", " ", line)`, then match EITHER order:
   - `<pageref> Title`: `^\s*([A-E]-?\d{1,3}|\d{1,4})\s+\D.*\S\s*$`
   - `Title <pageref>`: `^\D.*?\S\s+([A-E]-?\d{1,3}|\d{1,4})\s*$`

```python
_TOC_LABELS = ("contents", "index")
_LEADING_NUM = re.compile(r"^\s*([A-E]-?\d{1,3}|\d{1,4})\s+\D.*\S\s*$")
_TRAILING_NUM = re.compile(r"^\D.*?\S\s+([A-E]-?\d{1,3}|\d{1,4})\s*$")
_DOT_LEADER = re.compile(r"[.·…]{2,}")


def _is_toc_entry(line):
    collapsed = _DOT_LEADER.sub(" ", line)
    return bool(_LEADING_NUM.match(collapsed) or _TRAILING_NUM.match(collapsed))


def find_contents_page(pages_text):
    """First page (1-based) that has a contents LABEL and >= MIN_TOC_ENTRIES entry
    lines in either number-order. General across leading-#, trailing-#, dot-leader."""
    for idx, text in enumerate(pages_text, start=1):
        low = text.casefold()
        if not any(lbl in low for lbl in _TOC_LABELS):
            continue
        entries = sum(1 for ln in text.splitlines() if _is_toc_entry(ln))
        if entries >= MIN_TOC_ENTRIES:
            return 1, idx
    return 0, 0
```

### Task 5: Cross-check + orchestration — `filename_family_hint`, `classify_doc`

**Files:**
- Modify: `findociq/pipeline/classify/family.py`
- Modify: `findociq/pipeline/classify/test_family.py`

**Interfaces:**
- Consumes: everything from Tasks 1–4.
- Produces:
  - `filename_family_hint(stem: str) -> str` → `pillar3` | `slides` | `fs` | `""`.
  - `classify_doc(pdf_path: str) -> dict` → one manifest row with EXACTLY these keys in this order: `path, family, institution, period, fs_subtype, has_contents_page, contents_page_number, confidence, flags`. `flags` is a `;`-joined string (empty when clean). `has_contents_page`/`contents_page_number` are `""` for `slides`/`ERROR`; `fs_subtype` is `""` for non-fs. On any read/parse exception → `family="ERROR"`, `flags="unreadable: <exc>"`, institution/period still parsed from the filename (best effort).

**Filename hint map (spec §confidence+flags), casefolded stem:**
- `"pillar 3"` / `"pillar3"` → `pillar3`
- `"presentation"` / `"cfo"` / `"deck"` → `slides`
- any of `financial`, `results`, `highlights`, `performance`, `trading`, `press`, `media`, `condensed`, `interim` → `fs`

```python
def iter_pdfs(path_or_dir):
    p = Path(path_or_dir)
    if p.is_dir():
        return sorted(str(f) for f in p.rglob("*.pdf"))
    return [str(p)]


def build_manifest(paths):
    """One row per path, unconditionally (ERROR rows included)."""
    return [classify_doc(p) for p in paths]


def write_manifest_csv(rows, out_path):
    out = Path(out_path)
    out.parent.mkdir(parents=True, exist_ok=True)
    with out.open("w", newline="") as fh:
        w = csv.DictWriter(fh, fieldnames=_COLUMNS)
        w.writeheader()
        for r in rows:
            w.writerow(r)


def main(argv=None):
    ap = argparse.ArgumentParser(description="Document-family router → manifest.csv")
    ap.add_argument("path", help="a PDF file or a directory (walked recursively for *.pdf)")
    ap.add_argument("--out", default=str(Path(__file__).parent / "out" / "manifest.csv"))
    args = ap.parse_args(argv)
    paths = iter_pdfs(args.path)
    rows = build_manifest(paths)
    write_manifest_csv(rows, args.out)
    by_family = {}
    for r in rows:
        by_family[r["family"]] = by_family.get(r["family"], 0) + 1
    print(f"{len(rows)} rows -> {args.out}")
    print("  " + "  ".join(f"{k}={v}" for k, v in sorted(by_family.items())))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
