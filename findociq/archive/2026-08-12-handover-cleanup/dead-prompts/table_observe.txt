WHAT COUNTS AS A MERGE (vs an empty cell) — this is the distinction that matters:
- MERGE = ONE printed value that visually spans 2+ anchor columns (a single
          number centred or ruled across them). The value belongs to the span.
- EMPTY = an anchor-column position with NOTHING printed in this row. The column
          exists in the grid; this row just has no value there. An empty cell is
          NOT a merge. (A dash "-" is a value, not empty.)
- SHADE = a cell with a grey background, independent of its content.
